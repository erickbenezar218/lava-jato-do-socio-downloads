# Lava Jato do Sócio — Downloads

Instaladores do programa Windows do **Lava Jato do Sócio**.

## Versão oficial (loja)
**[Baixar LavaJatoDoSocio-Setup.exe](https://github.com/erickbenezar218/lava-jato-do-socio-downloads/releases/latest/download/LavaJatoDoSocio-Setup.exe)**

Abre o sistema da loja (dados reais). Use no computador do caixa.

## Versão de demonstração (teste)
**[Baixar LavaJatoDoSocio-DEMO-Setup.exe](https://github.com/erickbenezar218/lava-jato-do-socio-downloads/releases/download/demo-1.0.0/LavaJatoDoSocio-DEMO-Setup.exe)**

> A versão DEMO abre o ambiente de demonstração, com dados fictícios. Não use para vendas reais.
> As duas versões podem ficar instaladas no mesmo computador.

### Como instalar
1. Execute o instalador baixado.
2. Se o Windows mostrar "O Windows protegeu o computador", clique em **Mais informações** → **Executar assim mesmo** (o instalador ainda não tem assinatura digital).
3. Abra pelo atalho **Lava Jato do Sócio** (oficial) ou **Lava Jato do Sócio DEMO** (teste).

Requisitos: Windows 10 ou 11 (64 bits) e internet.
